# Distributed AI Systems Lab

Experiments in distributed training and AI systems.

## Repository Structure

```text
src/          Core implementations
experiments/  Experiments
benchmarks/   Performance measurements
configs/      Configurations
docs/         Notes and decisions
tests/        Tests
```

## Architecture

The project evolves from a single-GPU training baseline into a distributed
training system supporting multiple parallelism strategies.

See:

- [Roadmap](docs/roadmap.md)
- [Architecture](docs/architecture.md)
- [Engineering Decisions](docs/decisions.md)


The project focuses on understanding, implementing and benchmarking
important systems techniques rather than reimplementing existing
frameworks for completeness.
